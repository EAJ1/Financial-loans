# Bloom Finance

A responsive, accessible financial loans website concept built with HTML, CSS and JavaScript. Open `index.html` in your browser, or serve this directory with `python3 -m http.server 8000` and visit `http://localhost:8000`.

Includes an interactive illustrative repayment calculator, loan category shortcuts, mobile navigation, native expandable FAQs and an accessible summary dialog. The plant illustration is built with CSS; Google Fonts are optional with local font fallbacks.

This is a front-end demonstration. Bloom Finance is a placeholder brand. It does not accept applications, collect personal information or provide lending services. The calculator uses a sample 24% nominal annual interest rate with monthly amortisation and no fees. Replace the sample configuration, business details and content with the actual lender's approved information before a production launch. A production application workflow requires a secure backend.
